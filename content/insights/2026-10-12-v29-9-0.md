- **Platform/SRE — Plan:** Four HTTP/2 CVEs in the Docker daemon (daemon crash, memory exhaustion, flow-control bypass, CPU spike) are fixed in this release; none are KEV-listed and EPSS scores are near zero, so no active exploitation clock, but schedule an upgrade to v29.9.0 if running Docker Engine on cluster nodes or VM fleets.
- **CI/CD — Plan:** If Docker-in-Docker or a Docker socket is part of your build runners, the same HTTP/2 daemon vulnerabilities apply; plan to update the Docker Engine version in runner images or host provisioning to v29.9.0, no hard deadline but meaningful DoS risk in shared build infrastructure.

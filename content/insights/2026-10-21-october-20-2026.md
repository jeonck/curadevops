- **Platform/SRE — Plan:** Apigee X instances below 1-18-0-apigee-6 will be automatically updated within 7–21 days (by ~Nov 10). Verify your instances are not excluded due to the DNS misconfiguration in Known Issue 445936920 or use of the deprecated Apigee Java Library (removed Oct 16, 2025); excluded instances will be left on older versions.
- **CI/CD — Plan:** Cloud SDK 590.0.0 (released Oct 20) removes cloud-build-local and the app-engine-grpc component as breaking changes. Audit pipelines for any use of cloud-build-local for local Cloud Build testing and plan migration to alternatives before auto-upgrading the Cloud SDK to this version.

- **Platform/SRE — Plan:** Two breaking changes affect teams running Backstage: the catalog backend now rejects primitive-root filter predicates (any custom catalog queries or plugins using that pattern must be updated), and the Atlassian usernameMatchingUserEntityName resolver is removed (migrate to emailMatchingUserEntityProfileEmail). No forced deadline, but plan the upgrade and audit affected code before rolling this version out.

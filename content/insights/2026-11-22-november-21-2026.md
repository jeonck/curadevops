- **Platform/SRE — Plan:** PHP runtimes on App Engine flexible and Cloud Run functions require a manual rebuild and redeploy to pick up the patched versions (8.2.36/8.3.37/8.4.28/8.5.13); also remove the temporary session.upload_progress.enabled=0 mitigation from php.ini afterward. No confirmed active exploitation or KEV listing in signals, so Act ceiling isn't met, but teams running PHP workloads on these GCP services should queue this promptly.
- **CI/CD — Plan:** Pipelines using GCP Buildpacks to build PHP apps need a triggered rebuild to pick up the patched runtime; remove any session.upload_progress workaround baked into build configs. No deadline or supply-chain compromise confirmed, but this is a supply-chain hygiene action worth scheduling this sprint.

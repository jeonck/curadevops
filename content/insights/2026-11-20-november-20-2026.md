- **Platform/SRE — Plan:** Security update (GCP-2026-082) patches Java 17/21/25 runtimes on App Engine flexible and Cloud Run; App Engine standard auto-applies, but flexible and Buildpacks-based workloads require a manual rebuild and redeploy, plus removal of any JDK_JAVA_OPTIONS mitigations. No KEV or confirmed exploitation in the signals, so plan the rollout this sprint rather than treating it as an emergency.
- **CI/CD — Plan:** GCP Buildpacks is a build-time surface — teams using it for Java apps must trigger a rebuild to pull the patched runtime per bulletin GCP-2026-082, and remove any JDK_JAVA_OPTIONS flags added as temporary workarounds; no supply-chain compromise or hard deadline, so schedule the pipeline update promptly but no immediate all-hands.

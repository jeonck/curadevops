- **Platform/SRE — Plan:** The gcloud minikube component will be removed after January 31, 2027 — schedule migration to a standalone minikube install or alternative local-cluster tooling before that date. Cloud Monitoring's per-chart time-range override is now GA and worth adopting for long-duration observability dashboards alongside high-frequency charts.
- **CI/CD — Plan:** If any pipelines invoke gcloud's minikube component for integration-test clusters, plan migration to a standalone minikube binary before the January 31, 2027 removal; also audit scripts for the already-deprecated `gcloud storage buckets anywhere-caches pause` command and replace it in affected workflows.
